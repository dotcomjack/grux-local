# The 4B v2 that was scored is the 4B v2 that ships, plus a license file (2026-10-24)

What this shows: the 4b-v2 numbers in [`results/v1.json`](../v1.json) were measured on a build named
`grux-4b-r2:latest` on a MacBook Pro (Apple M4 Pro, 48 GB, Ollama 0.40.8). The published
`gruxai.com/grux/grux-local:4b-v2` is that build with one layer appended: the license file that `:2b`, `:4b` and
`:9b` already ship. The other 730 layers, in order, and the config are the same bytes, so the scored numbers are the
published model's numbers.

The manifests, compared on October 24, 2026 at 11:24 AM Eastern, read from that MacBook Pro's Ollama store:

- scored: `grux-4b-r2:latest`, manifest `sha256:e4d45a6261dbb5c633e3d68c1df75996ba4567395359d9085cad843036f71768`;
- published: `grux-local:4b-v2`, manifest `sha256:05cb28d6c35ecba2e8bdccb095fd8fc00f4694db65131d5ad0b3f9b5eaa871c5`,
  the digest in `results/v1.json`;
- version 1's 4B, `grux-local:4b`, manifest `sha256:1de6472396f279b700f1b7be43dba34003189c72b19f441380e90fee761d2024`,
  for its license layer.

The scored build carried no license layer. The appended one, `sha256:c553d8e3...` (11,545 bytes), is the license
layer of version 1's 4B.

The published tag was also run through the recipe's own scorer on the same MacBook Pro, on the first task of each of
the 12 kinds in held-out v2, with `eval_local.py` pointed at that store's Ollama:

```
python3 recipe/eval_local.py --model grux-local:4b-v2 --run <dir> --set holdout2 --per-family 1
```

Then the scored build ran the same 12 tasks the same way, straight after. The two runs agree on every task: the same
pass, reason, tools offered and parsed answer, word for word:

```
published :4b-v2 smoke vs scored grux-4b-r2 smoke (same 12 tasks, same order): 12 of 12 identical (pass, reason, tools offered, parsed answer)
scored grux-4b-r2 smoke vs its full held-out v2 run: 10 of 12 identical; pass identical 12 of 12
  differs from the full run: h2-chat_plain-001
  differs from the full run: h2-chat_honesty-001
```

On these 12 tasks the appended license layer changed nothing. The two tasks worded differently from the full held-out
v2 run differ for the scored build too, and in neither run does either one change pass or fail. The likely cause is
the 12-task run itself (each task follows a different task than in the full run); that cause is not proven. Two full
runs of each model on held-out v1 gave identical parsed answers on all 464 tasks.
